# Algorithm Practice

用于记录在不同刷题平台完成的题目、代码和解题思路。

## 目录

| 目录 | 平台 |
| --- | --- |
| LeetCode | 力扣 |
| NowCoder | 牛客 |
| Luogu | 洛谷 |
| Codeforces | Codeforces |
| Other | 其他平台 |

## 文件命名规则

统一使用：

~~~text
平台_题号_题目名.语言后缀
~~~

示例：

~~~text
LeetCode_0001_Two_Sum.c
LeetCode_0206_Reverse_Linked_List.cpp
NowCoder_01_Reverse_List.c
Luogu_P1001_A_plus_B.c
~~~

题目名称建议使用英文或拼音，并使用下划线分隔单词，避免文件名中出现特殊符号。

## 每道题建议记录

- 题目链接；
- 题目所属平台和难度；
- 解题思路；
- 时间复杂度和空间复杂度；
- 最终通过的代码；
- 做题日期和复盘记录。

## 推荐工作流程

~~~text
完成题目
→ 按命名规则保存代码
→ 在代码旁记录思路
→ git add .
→ git commit -m "feat: add platform problem"
→ git push
~~~
